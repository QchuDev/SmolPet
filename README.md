# SmolPet

A little Python project to challenge myself and gift my girlfriend something good ❤️

## Description

SmolPet is a personal Python project created with love.

## Installation

```bash
# Clone the repository
git clone https://github.com/Cuchu59/SmolPet.git
cd SmolPet

# Install dependencies
pip install -r requirements.txt

# Install the package
pip install -e .
```

## Usage

```bash
# Run the application
python -m smolpet.main
# Or if installed:
smolpet
```

## Development

```bash
# Install in development mode
pip install -e .
```
